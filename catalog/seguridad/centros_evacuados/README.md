# Centros de evacuados ante riesgo

Centros de evacuación ante casos de emergencia dentro del marco de la Gestión de Riesgo.

| | |
|---|---|
| Identificador | `seguridad/centros_evacuados` |
| Geometría | puntos |
| Fuente | [Centros de evacuados ante riesgo en GeoNode](https://geonode.pergamino.gob.ar/catalogue/#/dataset/101), capa WFS `geonode:centros_evacuados` |
| Licencia | [CC-BY-SA-4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| Actualización declarada por la fuente | cuando es necesario |

## Propósito

Según el registro de GeoNode:

> Los centros de evacuados sirven como lugares temporales donde es posible encontrar refugio ante situaciones climatológicas de gran magnitud, como por ejemplo en inundaciones.

## Calidad de los datos

Según el registro de GeoNode:

> El dato fue aportado por Defensa Civil Pergamino.

## Esquema

| Columna | Tipo |
|---|---|
| `geometry` | binary |
| `id` | int64 |
| `nombre` | string |
| `direccion` | string |
| `zona` | string |
| `capacidad` | string |
| `fuente` | string |
| `observaciones` | string |
| `bbox` | struct<xmin: double, ymin: double, xmax: double, ymax: double> |

La fuente no publica descripciones de columnas: GeoNode devuelve una descripción vacía para cada atributo. Por eso las columnas no tienen descripción en `table:columns`, salvo `geometry` y `bbox`, que agrega este catálogo.

## Acceso

```python
import duckdb

con = duckdb.connect()
con.sql("INSTALL spatial; LOAD spatial; INSTALL httpfs; LOAD httpfs;")
con.sql("SELECT * FROM read_parquet('https://data.source.coop/nlebovits/pergamino-ide/seguridad/centros_evacuados/centros_evacuados.parquet') LIMIT 10").show()
```

## Versiones

Cada extracción que cambia los datos es una versión nueva. La versión actual está en `./centros_evacuados.parquet`. Las anteriores son los activos `version-*` de `collection.json`, con el número de registros y la suma de verificación de cada una. Sus archivos no cambian.

La primera versión proviene del GeoServer anterior de la IDE Pergamino y sigue publicada en `./publico_centros_evacuados.parquet`.
