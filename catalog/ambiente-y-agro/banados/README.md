# Bañados

Capa de bañados de la cuenca del Arroyo Pergamino. La extensión de la capa supera el territorio del Partido de Pergamino.

| | |
|---|---|
| Identificador | `ambiente-y-agro/banados` |
| Geometría | polígonos |
| Fuente | [Bañados en GeoNode](https://geonode.pergamino.gob.ar/catalogue/#/dataset/65), capa WFS `geonode:banados` |
| Licencia | [CC-BY-SA-4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| Actualización declarada por la fuente | no planificada |

## Propósito

Según el registro de GeoNode:

> Los bañados son extensiones de tierra planas que permanecen inundadas o con el suelo saturado de agua de manera temporal o intermitente. Funcionan como ecosistemas de transición (humedales) entre ambientes terrestres y acuáticos, caracterizados por una alta biodiversidad y vegetación adaptada a la humedad.

## Calidad de los datos

Según el registro de GeoNode:

> Los datos fueron extraídos de planos existentes en la ex Secretaría de Obras Públicas.

## Esquema

| Columna | Tipo |
|---|---|
| `id` | int64 |
| `area` | double |
| `perimetro` | double |
| `fuente` | string |
| `geometry` | binary |
| `bbox` | struct<xmin: double, ymin: double, xmax: double, ymax: double> |

La fuente no publica descripciones de columnas: GeoNode devuelve una descripción vacía para cada atributo. Por eso las columnas no tienen descripción en `table:columns`, salvo `geometry` y `bbox`, que agrega este catálogo.

## Acceso

import duckdb

## Versiones

Cada extracción que cambia los datos es una versión nueva. La versión actual está en `./banados.parquet`. Las anteriores son los activos `version-*` de `collection.json`, con el número de registros y la suma de verificación de cada una. Sus archivos no cambian.

La primera versión proviene del GeoServer anterior de la IDE Pergamino y sigue publicada en `./publico_banados.parquet`.
