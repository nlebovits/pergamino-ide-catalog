# Curvas de nivel (IGN)

Curvas de nivel o isolineas del Instituto Geográfico Naciona (IGN) con paso de 10m, recortado al Partido de Pergamino.

| | |
|---|---|
| Identificador | `ambiente-y-agro/curvas_nivel_ign` |
| Geometría | líneas |
| Fuente | [Curvas de nivel (IGN) en GeoNode](https://geonode.pergamino.gob.ar/catalogue/#/dataset/129), capa WFS `geonode:curvas_nivel_ign` |
| Licencia | [CC-BY-SA-4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| Actualización declarada por la fuente | no planificada |

## Calidad de los datos

Según el registro de GeoNode:

> El dato se obtuvo a partir de datasets publicados por el IGN.

## Esquema

| Columna | Tipo |
|---|---|
| `id` | int64 |
| `cota` | int64 |
| `hoja` | string |
| `fuente` | string |
| `geometry` | binary |
| `bbox` | struct<xmin: double, ymin: double, xmax: double, ymax: double> |

La fuente no publica descripciones de columnas: GeoNode devuelve una descripción vacía para cada atributo. Por eso las columnas no tienen descripción en `table:columns`, salvo `geometry` y `bbox`, que agrega este catálogo.

## Acceso

```python
import duckdb

con = duckdb.connect()
con.sql("INSTALL spatial; LOAD spatial; INSTALL httpfs; LOAD httpfs;")
con.sql("SELECT * FROM read_parquet('https://data.source.coop/nlebovits/pergamino-ide/ambiente-y-agro/curvas_nivel_ign/curvas_nivel_ign.parquet') LIMIT 10").show()
```

## Versiones

Cada extracción que cambia los datos es una versión nueva. La versión actual está en `./curvas_nivel_ign.parquet`. Las anteriores son los activos `version-*` de `collection.json`, con el número de registros y la suma de verificación de cada una. Sus archivos no cambian.

La primera versión proviene del GeoServer anterior de la IDE Pergamino y sigue publicada en `./publico_curvas_nivel_ign.parquet`.
