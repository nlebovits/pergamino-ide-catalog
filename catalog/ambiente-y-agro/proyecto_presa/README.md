# Proyecto presa Pergamino

Proyecto presa de contención para la Ciudad de Pergamino, actualmente en licitación/ejecución.

| | |
|---|---|
| Identificador | `ambiente-y-agro/proyecto_presa` |
| Geometría | líneas |
| Fuente | [Proyecto presa Pergamino en GeoNode](https://geonode.pergamino.gob.ar/catalogue/#/dataset/232), capa WFS `geonode:proyecto_presa` |
| Licencia | [CC-BY-SA-4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| Actualización declarada por la fuente | no planificada |

## Propósito

Según el registro de GeoNode:

> El proyecto prevee contener el caudal de agua que en exceso no puede transportar el Arroyo Pergamino en su máxima capacidad. Permitirá prevenir inundaciones en la Ciudad de Pergamino.

## Calidad de los datos

Según el registro de GeoNode:

> El proyecto de la presa de contención fue tomado directamente de los planos del proyecto provincial.

## Esquema

| Columna | Tipo |
|---|---|
| `id` | int64 |
| `nombre` | string |
| `link` | string |
| `recurrencia` | string |
| `expediente` | string |
| `foto` | string |
| `geometry` | binary |
| `bbox` | struct<xmin: double, ymin: double, xmax: double, ymax: double> |

La fuente no publica descripciones de columnas: GeoNode devuelve una descripción vacía para cada atributo. Por eso las columnas no tienen descripción en `table:columns`, salvo `geometry` y `bbox`, que agrega este catálogo.

import duckdb

## Versiones

Cada extracción que cambia los datos es una versión nueva. La versión actual está en `./proyecto_presa.parquet`. Las anteriores son los activos `version-*` de `collection.json`, con el número de registros y la suma de verificación de cada una. Sus archivos no cambian.

La primera versión proviene del GeoServer anterior de la IDE Pergamino y sigue publicada en `./publico_proyecto_presa.parquet`.
