# Ambiente y agro

Arbolado urbano, espacios verdes, suelos y cultivos INTA, hidrografía y cuencas, curvas de nivel, isohietas, carbono en el suelo, inundaciones históricas y el proyecto de presa. Incluye datos de INTA, IGN e INA rehospedados por el municipio.

Forma parte del espejo cloud-native de la [IDE Pergamino](../README.md).

## Acceso

Cada colección tiene su README con el esquema, y su AGENTS.md con consultas probadas. Por ejemplo:

```python
import duckdb

con = duckdb.connect()
con.sql("INSTALL spatial; LOAD spatial; INSTALL httpfs; LOAD httpfs;")
con.sql("SELECT * FROM read_parquet('https://data.source.coop/nlebovits/pergamino-ide/ambiente-y-agro/arbolado/arbolado.parquet') LIMIT 10").show()
```
