## Calidad de los datos

Según el registro de GeoNode:

> El dato se obtuvo a partir de registros municipales.

## Esquema

| Columna | Tipo |
|---|---|
| `geometry` | binary |
| `id` | int64 |
| `gid` | int64 |
| `nombre` | string |
| `direccion` | string |
| `telefono` | string |
| `sitio web` | string |
| `mail` | string |
| `tipo` | string |
| `bbox` | struct<xmin: double, ymin: double, xmax: double, ymax: double> |

La fuente no publica descripciones de columnas: GeoNode devuelve una descripción vacía para cada atributo. Por eso las columnas no tienen descripción en `table:columns`, salvo `geometry` y `bbox`, que agrega este catálogo.

## Acceso

```python
import duckdb

con = duckdb.connect()
con.sql("INSTALL spatial; LOAD spatial; INSTALL httpfs; LOAD httpfs;")
con.sql("SELECT * FROM read_parquet('https://data.source.coop/nlebovits/pergamino-ide/comercio-y-cultura/medios_de_comunicacion/medios_de_comunicacion.parquet') LIMIT 10").show()
```

## Versiones

Cada extracción que cambia los datos es una versión nueva. La versión actual está en `./medios_de_comunicacion.parquet`. Las anteriores son los activos `version-*` de `collection.json`, con el número de registros y la suma de verificación de cada una. Sus archivos no cambian.

La primera versión proviene del GeoServer anterior de la IDE Pergamino y sigue publicada en `./publico_medios_de_comunicacion.parquet`.
