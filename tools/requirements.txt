# What tools/refresh.py and the generators need. Install into a virtualenv,
# not the system Python:
#
#   python3 -m venv .venv
#   .venv/bin/pip install -r tools/requirements.txt
#
# The packages that write published bytes are pinned exactly, so a refresh
# writes the same file shape as the version before it:
#
# - portolan-cli runs the WFS extract and converts the SLD style. It is
#   pinned to the commit of tag v0.9.0.
# - geoparquet-io reprojects, sorts and builds PMTiles. The PMTiles step needs
#   tippecanoe on PATH, which this file cannot install. On Ubuntu:
#   sudo apt-get install -y tippecanoe
#
# rashid is not here. portolan-cli 0.9.0 requires rashid<0.4.0, and this
# catalog conforms to Portolan v0.3.0, which rashid 0.4.0 checks. Install
# rashid in its own environment, so the two do not resolve against each
# other:
#
#   pipx install rashid==0.4.0
